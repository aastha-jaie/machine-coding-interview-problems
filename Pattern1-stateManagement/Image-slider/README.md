Question:

Create a simple image slider component in React to display a set of product images fetched from an API. The slider should enable users to navigate through the images using “Next” and “Previous” buttons, allowing for smooth transitions between them.

Input Examples:

1. Initial render with fetched product images.
2. Clicking the “Next” button to move to the next image.
3. Clicking the “Previous” button to move to the previous image.

Expected Output Examples:

1. Display a set of product images in a slider format.
2. Transition smoothly to the next image when clicking “Next”.
3. Transition smoothly to the previous image when clicking “Previous”.
